# 杯标（cup tag）复刻

## 文件

- `cup_tag.scad` — 复刻模型；中心图案由 SVG 阴刻，参数集中在文件末尾
- `图案-星形.svg` — 默认图案：从原 STL 提取的星形，按真实毫米尺寸绘制
- `cup_tag_rebuilt.stl` — 按默认参数导出的打印件（原 `cup_tag.stl` 未改动）
- `预览-等轴.png` — 默认参数预览
- `对比-原版与复刻.png` — 同相机、同比例对比

## 尺寸（实测/设定）

| 项目 | 数值 |
|---|---|
| 圆盘半径 | 12.5 mm |
| 总厚度 | 3.0 mm |
| 平切边到圆心 | 9.034 mm（原模型实测；设计意图约 9 mm） |
| 阴刻深度 | 0.8 mm（槽底 z=2.2，剩余底厚 2.2） |
| 整体外形 | 27.884 × 25.222 × 3.0 mm |
| 夹子最窄开口 | 约 0.43 mm（与原模型一致） |

## 坐标

- 圆盘圆心 = (0, 0)，+Z = 顶面（阴刻面），底面 z = 0。
- 图案默认外接框中心 = `[-1.1786, 0.6706]`，即原模型星形的位置（相对圆盘中心略偏左上）。
- 若要让图案正对圆盘几何中心，把 `PATTERN_CENTER` 改为 `[0, 0]`。

## 更换 SVG 图案

1. 直接替换 `图案-星形.svg`（保持文件名），或修改 `PATTERN_SVG` 指向新的 SVG 文件。
2. 推荐 SVG 用毫米单位（`width="..." height="..."`），会按实际尺寸导入。
3. 不想计算比例时，设置 `PATTERN_FIT_WIDTH = 17` 之类，按宽度等比缩放（此时忽略 `PATTERN_SCALE`）。
4. `PATTERN_ROT` 控制旋转，`PATTERN_MIRROR` 控制左右镜像，`PATTERN_CENTER` 控制位置。
5. 文字必须先转曲；线稿要转成填充轮廓。OpenSCAD 不认 SVG 的描边和颜色，所有路径都会作为实体被挖掉。
6. 删除白色背景矩形、边框、水印，否则会被一起刻掉。
7. 图形内部的孔洞（`fill-rule="evenodd"` 的多个子路径）会保留成中心岛。

## 注意

- 外形是根据原 STL 的等截面轮廓数字化的，所以 R12.5、切边 9.034 和 J 形夹都是固定轮廓，不是用圆 + 布尔重新近似出来的。若要改圆半径或切边距离，需要另做参数化外形。
- 夹子最窄处只有约 0.43 mm；FDM 打印时这是一条很窄的缝，切片前请在预览里确认不会粘连。原模型就是这个尺寸，本复刻没有加宽。
- 默认平放打印：底面贴床，星形阴刻面朝上。
- 换 SVG 后需要重新导出 STL；原 `cup_tag.stl` 始终没有被覆盖。
